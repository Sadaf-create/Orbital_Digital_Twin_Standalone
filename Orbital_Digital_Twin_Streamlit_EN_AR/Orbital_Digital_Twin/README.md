# Orbital Digital Twin | التوأم الرقمي المداري

Standalone Streamlit prototype. Python 3.10+. Fictional inputs throughout.

## Windows

Extract the archive and open PowerShell in the folder with app.py.

    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1

On macOS/Linux, create the environment with python3 and replace the Windows Python path with .venv/bin/python. Visit http://localhost:8501 if the browser does not open automatically.

## Demonstration

Move the exercise phase slider. Select SAT-B as unavailable and compare the number of available relays for each service.

## العرض بالعربية

شغّل التطبيق ثم اختر العربية من أعلى الصفحة. حرّك مؤشر مرحلة التمرين، ثم اختر تعطّل SAT-B وقارن عدد أقمار الترحيل المتاحة لكل خدمة.
